# Ohmyfood : Finis les temps d'attente au restaurant !

L'application répertorie les menus de restaurants gastronomiques et permet de choisir les plats.

## 🎯 Objectifs pédagogiques du projet :
- Mettre en œuvre des effets CSS graphiques avancés.
- Mettre en place une structure de navigation pour un site web.
- Mettre en place son environnement Front-End.
- Utiliser un système de gestion de versions pour le suivi du projet et son hébergement.

## ✅ Missions effectuées :
- Intégration du prototype réalisé avec Figma.
- Fonctionnalité de sélection de menus.
- Fonctionnalité de sélection de plats.
- Animations CSS.
- Interface responsive.

## 🛠 Technos : HTML + CSS
